# Windy Hills

This is a mod for Minecraft that adds the Windy Hills Biome with formations like inselbergs, mushroom rocks and arches, as well as wind that is constantly changing and pushes the player around.

## Features:
1. Adds the Windy Highlands Biome
2. Adds various structures such as eroded arches, inselbergs and mushroom rocks.
3. Adds wind that can affect player movement
4. Increases Iron ore generation on the surface of the Windy Highlands Biome
